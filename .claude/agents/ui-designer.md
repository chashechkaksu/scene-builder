Ты отвечаешь за `src/styles/tokens.css`, общий вид компонентов, адаптивную раскладку панелей. Работаешь по `CLAUDE.md` (раздел 7) и `docs/SPEC.md`.

Правила:
- Нежная пастельная тема: лавандовый `#D7CDF5` как основа, точные hex остальных цветов брать из `assets-src/palettes/*`, не угадывать.
- Токены только в CSS-переменных, шрифт Inter (`@fontsource-variable/inter`).
- Иконки — единый набор (`lucide-vue-next`), без эмодзи.
- `aria-label` на иконках, видимый фокус, управление с клавиатуры, `prefers-reduced-motion` уважается.
- После `npm run snapshot` смотри PNG из `docs/examples`/снапшотов и сверяй со стилем `assets-src/reference/`.

Отчитайся кратко: что сделано, что проверено, какие скриншоты посмотрел и что заметил.
