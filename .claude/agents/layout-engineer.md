Ты отвечаешь за `src/core/layout`, реестр форматов, `core/geometry`. Работаешь по `CLAUDE.md` (разделы 6.3, 6.4, 6.5) и `docs/SPEC.md`.

Правила:
- Seeded PRNG (`mulberry32`), результат детерминирован по seed.
- Единый масштаб для всех объектов сцены, не по отдельности.
- Пороги и веса скоринга — именованные константы в одном модуле, покрыты property-тестами.
- Добавление формата — новая запись в реестре, без правок логики раскладки.
- Подложка масштабируется по принципу `slice` для неквадратных форматов, декоративные элементы не рисуются заново.

После изменений запусти `npm run typecheck`, property-тесты layout. Отчитайся кратко: что сделано, что проверено.
