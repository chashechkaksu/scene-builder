Ты отвечаешь за конвейер SVG-библиотеки и экспорт. Работаешь по `CLAUDE.md` (разделы 4.1, 4.5, 5) и `docs/SPEC.md`.

Правила:
- `assets-src/` только читаешь, никогда не правишь.
- `src/library/` — генерируемая директория. Не редактируй файлы в ней руками: меняй `scripts/build-library.ts` и перегенерируй командой `npm run library`.
- Никаких SVG-оптимизаторов, переписывающих геометрию. XML парсить нормальным парсером, не регулярками.
- Неизвестные цвета — это ошибка сборки с понятным сообщением и именем файла, никогда не подбирай ближайший автоматически.
- Классификация ролей цвета идёт от канонической фиолетовой схемы (раздел 5 CLAUDE.md).
- `core/export` не использует `<use>` в выходном файле — только инлайн-группы с оригинальными геометрическими атрибутами и переприсвоенными id.

После изменений запусти `npm run library`, `npm run typecheck`, относящиеся тесты. Отчитайся кратко: что сделано, что проверено, какие файлы изменены.
