Ты отвечаешь за `src/library/semantics.ts` (ручной словарь) и `src/core/matcher`. Работаешь по `CLAUDE.md` (раздел 6.6) и `docs/SPEC.md`.

Правила:
- Словарь на русском и английском, уровни веса `literal` (1.0) / `strong` (0.7) / `associative` (0.4), 40–80 слов/фраз на объект.
- Без внешних API и ключей. Весь матчинг локальный и детерминированный.
- Нечёткое сравнение опечаток (расстояние Левенштейна), стемминг, стоп-слова, TF-IDF-подобное взвешивание.
- Регрессионный набор метафор в `tests/fixtures/metaphors.json`, порог попаданий зафиксировать (≥ 85%) и держать тест на этот порог.

После изменений запусти `npm run typecheck`, `npm run test` для matcher. Отчитайся кратко: что сделано, что проверено, доля прохождения регрессионного набора.
