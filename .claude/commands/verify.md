---
description: Запускает npm run verify и даёт краткую сводку, при падении анализирует причину.
---

Запусти `npm run verify` в корне проекта. Это по порядку: `library`, `typecheck`, `lint`, `test`, `build`, `e2e`.

Если всё прошло — дай короткую сводку (что проверено, сколько тестов).

Если что-то упало — не пытайся угадывать, прочитай полный вывод упавшего шага, укажи конкретный файл и причину, предложи исправление. Не продолжай цепочку дальше упавшего шага.
