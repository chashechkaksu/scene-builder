description: Рендерит примеры сцен в PNG (npm run snapshot) и проводит визуальный осмотр.
---

1. Запусти `npm run snapshot`.
2. Прочитай (посмотри) получившиеся изображения.
3. Сравни со стилем `assets-src/reference/` (пропорции, цвета, компоновка, нет ли вылезших объектов).
4. Опиши конкретные замечания, если есть — что отличается от референса и в каком файле/сцене.
