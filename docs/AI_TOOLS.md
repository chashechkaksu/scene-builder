# Использованные AI-инструменты

## Claude Code (Anthropic)

- Вся разработка: скрипт сборки библиотеки, `core/*` (export, layout, matcher, palette), Pinia-сторы, Vue-компоненты, тесты (Vitest/Playwright), CSS-токены — агент-оркестратор с делегированием подзадач специализированным субагентам (роли описаны в `.claude/agents/`: `svg-pipeline`, `editor-engineer`, `layout-engineer`, `semantic-matcher`, `ui-designer`, `qa-tester`, `code-reviewer`, `spec-auditor`).
- Составление семантического словаря для сценария 1 (`src/library/semantics.ts`): 10 объектов × 40–80 слов и фраз на русском и английском языках, три уровня веса (буквальное/сильное/ассоциативное значение), проверен и доработан по регрессионному набору метафор (`tests/fixtures/metaphors.json`).

## Чего не использовалось

- Никаких внешних LLM API/ключей в продукте. Подбор объектов по метафоре (сценарий 1) работает полностью локально, без сети.
- Никаких AI-инструментов для генерации самих иллюстраций — все объекты взяты из готовой Figma-библиотеки и не меняются.
